## 1. How to read this file

**Confidence legend**

| Tag | Meaning |
|---|---|
| VERIFIED | Two or more independent sources agree. Safe to state plainly. |
| SINGLE | One source only. May be true; state modestly, attribute it, or gate it. |
| CONFLICT | Sources disagree. Both versions are recorded; see §13. Ships gated. |
| UNVERIFIED | Surfaced in research but not clearly stated, or not clearly attributable to a specific page. Ships gated or not at all. |
| OWNER | Must be confirmed by the owner at the counter before it ships ungated. |

**Gating rule.** Anything tagged OWNER, UNVERIFIED or CONFLICT ships gated: rendered as an em-dash with a "confirm with the bar" chip, or omitted. The static HTML default is the gated state; the flags in `js/site.js` only ever un-gate. A fact can carry two tags (e.g. SINGLE + OWNER); the stricter one governs.

**Ids.** Every fact has a stable id (F001, F002 …). HTML comments cite them (`<!-- F053 -->`). Never renumber; append new ids at the end of a section.

**Universal caveat — read before trusting any "verbatim" below.** The research environment could not open a single page body: Yelp, TripAdvisor, Facebook, Star-Advertiser, Honolulu Magazine, Weebly, Giftly, Uber Eats and every other domain were blocked at the proxy (dead ends DE#49, DE#71, DE#92). Every snippet in this file is what a search engine's result summary relayed, so "verbatim" means verbatim-as-relayed, and several listing sentences were attributed to a page by inference from the result set (noted as "attribution inferred"). Consequences: (1) any quote that goes on the page gets a 10-second eyeball on the live page from Kevin's phone before launch; (2) every price and every hour in this file is a snapshot, not a fact about tonight.

**Dates.** "undated" = the page showed no date. Listing counts carry the snapshot date. A fact from 2010–2015 describes the bar then, not now, and is labelled historic.

**Excluded-venue sources.** Two Star-Advertiser pieces whose headline subject is the owners' closed Kapolei venue (see §14) each contain one sentence about Café Duck Butt. Those sentences are recorded for completeness and flagged "[excluded-venue article]"; they are never cited on the site.

**Source-format note.** Bullets read `- Fnnn — claim [TAG — Source, date — url]`. Where several sources agree they share one line, separated by `;`.
